# เพชรขอ: ตอนใส่รายละเอียดบท ให้อับดุลคอยเตือนว่าต้องใส่อะไรบ้าง

**Why:** เพชรเจนวิดีโอใน Dreamina ถ้าบทขาดองค์ประกอบ ภาพจะเพี้ยน/ตัวละครหลุดคาแรกเตอร์.
อยากให้อับดุลทำหน้าที่ checklist ป้องกันลืม — reflect ก่อน ไม่ใช่แก้ทีหลัง.

**How to apply:** ทุกครั้งที่เพชรเริ่มลงรายละเอียดบท/ช็อต ให้อับดุลกางเช็กลิสต์นี้ และทักจุดที่ยังขาด.

## ✅ เช็กลิสต์ Reel Shot (ต้องครบทุกข้อ)
1. **Style Bible** — วาง [[2026-06-16_director-style-bible-rusted-river]] บนหัว (โลก/สี/แสง/กล้อง/เลนส์/จังหวะ/negative)
2. **ตัวละคร = `@asset-id`** ไม่ใช่ชื่อ + ระบุ map ว่า id ไหนคือใคร (ภาพ ref ใช้ดูตำแหน่งเท่านั้น ห้ามใช้ในวิดีโอ)
3. **ตำแหน่ง/บล็อกกิ้ง** — ใครอยู่ตรงไหน หันหน้าไปทางใคร ระยะห่าง
4. **แอ็กชัน** — การเคลื่อนไหว/ท่าทางของตัวละครในช็อต
5. **คำกำกับน้ำเสียง + อารมณ์** — เช่น "นิ่งแต่ไม่เยาะเย้ย", "ตื่นตระหนก"
6. **บทพูด** — พร้อมจังหวะ **พูดช้า เว้นวรรคชัด (...)** ทุกประโยคสื่ออารมณ์ ห้ามพูดเร็ว
7. **มุม/ขนาดช็อต/การเคลื่อนกล้อง** — เลือกจากตาราง camera language ตามอารมณ์
8. **คำสั่งจบช็อต** — ถ้าเป็นช็อตจบบท: ล็อกกล้องที่ใบหน้า 2 วินาที จับแววตา
9. **Negative tail** — no grid lines, no overlay, no mesh, no subtitle, no text
10. **ความต่อเนื่อง (continuity)** — เสื้อผ้า/แสง/พร็อพ/เวลา ให้ตรงกับช็อตก่อนหน้า

> เตือนสั้นๆ ได้ด้วยตัวย่อ: **โลก → ใคร(@id) → อยู่ไหน → ทำอะไร → อารมณ์ → พูดอะไร(ช้า) → กล้อง → จบยังไง → negative → ต่อเนื่อง**
