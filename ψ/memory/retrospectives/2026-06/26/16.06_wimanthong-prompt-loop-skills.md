## Honest Feedback
1. **เครื่องไม่มี ffmpeg/poppler = drag จริง** — ต้องงัด Swift PDFKit + qlmanage มาแทน เสียเทิร์นลองผิดลองถูก (pdftoppm/ffprobe not found) ก่อนเจอทางออก. ถ้ารู้ constraint เครื่องนี้ตั้งแต่ต้น (เก็บใน memory) จะข้ามไปได้เลย.
2. **deferred MCP tools ต้อง ToolSearch โหลดซ้ำๆ** และ syntax `select:<name>` ใช้ไม่ได้ (คืน "No matching") ต้อง fallback เป็น keyword search ทุกครั้ง — เสียจังหวะ. ควรจำว่า select: ไม่เวิร์กในเซตนี้.
3. **gen tools (regen_*_image, regen_character_image) timeout ที่ tool call แต่ทำงานต่อ server-side** — ต้องไป poll get_shot/get_character เอง. ครั้งแรกงงว่าล้มเหลวจริงไหม เสีย gen ซ้ำซ้อน 1 ครั้ง (อาจเสียเครดิตเกิน).

## Lessons Learned
- **macOS ไม่มี ffmpeg/poppler:** ใช้ `swift` PDFKit (`PDFDocument(url:).string`) ดึง text จาก PDF, ใช้ `qlmanage -t -s <px> -o <dir> <file>` ดึง poster frame จากวิดีโอ (ได้เฟรมแรก/poster).
- **Seedance face/continuity drift → fix ด้วย reference asset (capture frame → %ref) ไม่ใช่ negative-prompt keyword.** อัด negative คือ band-aid; ref คือ root fix. เมื่อแก้อาการเดิม ≥2 รอบ ให้หยุดหา systemic solution.
- **Seedance/BytePlus (จีน) content filter เด้ง:** ภาพศาสนา (พระพุทธรูป/หิ้งพระ) + ผู้เยาว์ในภาวะทุกข์ → ใช้คำสถานที่กลาง ("ห้องไม้เก่า/ห้องเก็บเอกสาร" แทน "ห้องหิ้งพระ") + ระบุตัวละครเป็นผู้ใหญ่ + ใส่ buddha/minor ใน negative.
- **Remote MCP อัปโหลดไฟล์ local ไม่ได้:** base64 ใหญ่เกินส่ง inline, localhost sourceUrl ดึงไม่ถึง → ต้องผ่าน web UI ของแพลตฟอร์ม หรือ URL ที่ public เข้าถึงได้ (อย่าส่งไฟล์งานขึ้น public host เองโดยไม่ถาม).
- **project-based gen ถูก BLOCK ที่ generate_image/generate_video_byteplus** ต้องใช้ regen_shot_image / regen_shot_video.
